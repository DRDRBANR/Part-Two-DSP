# Моделирование алгоритмов ЦОС в MATLAB

В директории представлены исходные скрипты для первой части тестового задания, посвященной цифровой обработке сигналов. Файлы содержат как ручную математическую реализацию алгоритмов, так и решения с использованием встроенных функций.

**Filter.m**
Вспомогательный скрипт для расчета коэффициентов и анализа характеристик цифрового фильтра нижних частот.

**Interpolate.m**
Ручная реализация интерполяции исходного сигнала в 3 раза, демонстрирующая алгоритм расширения массива нулевыми отсчетами и работу скользящего окна сглаживающего фильтра.

**Simple_interpolate.m**
Упрощенный вариант скрипта для кратного увеличения частоты дискретизации сигнала с помощью функций среды моделирования.

**DEC.m**
Полный алгоритм дробного ресэмплирования (изменение частоты в 3/5 раза). Включает ручную вставку нулей, расчет КИХ-фильтра, математическую свертку, компенсацию групповой задержки и децимацию.

**Simple_DEC.m**
Компактная реализация дробного ресэмплирования с использованием встроенных функции MATLAB.

**OFDM.m**
Модель TX системы OFDM. Скрипт позволяет динамически изменять разнос поднесущих, размерность FFT, длину циклического префикса (CP) и схему модуляции (QPSK, 16-QAM, 64-QAM, 256-QAM) с выводом графических данных.
