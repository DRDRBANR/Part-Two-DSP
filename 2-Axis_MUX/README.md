# Параметризируемый AXI-Stream Мультиплексор

## Описание
Модуль представляет собой мультиплексор потоковых данных.. Устройство предназначено для маршрутизации одного из входных потоков на единственный выходной интерфейс (Master) на основе управляющего сигнала выбора. В базовой конфигурации модуль работает в режиме 2:1, однако архитектура поддерживает параметрическое расширение до произвольного количества портов N.

## Особенности реализации
Модуль соблюдает протокол рукопожатия AXI-Stream. Если на выбранном входном порту отсутствуют валидные данные, мультиплексор удерживает шину в неактивном состоянии, не допуская передачи данных. Неактивные в настоящий момент порты полностью изолируются от выходной логики. Для таких портов сигнал готовности к приему жестко устанавливается в логический ноль.

Если принимающее устройство на выходном интерфейсе не готово к обработке данных и снимает сигнал готовности, мультиплексор транслирует это состояние на активный входной порт. При этом текущее значение на шине данных и сигнал валидности удерживаются активными до момента подтверждения успешной транзакции приёмником.

## Структура директории
Директория `src` содержит RTL-код мультиплексора `axis_mux.sv`. В директории `tb` расположен тест `tb_axis_mux.sv`, который эмулирует поведение AXI-stream и проверяет изоляцию невыбранных портов, а также backressure. В корне папки находится исполняемый Tcl-скрипт `run_sim.tcl`.

## Как запустить симуляцию
Для автоматической сборки проекта и запуска испытательного стенда необходимо открыть Tcl Console в среде разработки Vivado. После перехода в директорию задания с помощью команды `cd` следует выполнить скрипт командой `source run_sim.tcl`. Среда автоматически сформирует проект, подключит необходимые интерфейсы и проведет тестирование модуля с выводом отчета о транзакциях в консоль.
