# Синхронное FIFO на базе примитива RAMB36E2

## Описание
Данный модуль реализует синхронное FIFO с параметризируемой разрядностью данных и прямым инстанцированием аппаратного примитива памяти **RAMB36E2**.

## Особенности реализации
* **Параметризация:** Разрядность шины данных (`DATA_WIDTH`) задается параметром при инстанцировании.
* **Аппаратная привязка:** Использование примитива `RAMB36E2` напрямую исключает непредсказуемость автоматического вывода памяти (BRAM inference) синтезатором Vivado.
* **Управление указателями:** Реализована схема с кольцевыми указателями записи и чтения, а также флагами заполненности (`full`, `empty`).

## Структура директории
* `src/sync_fifo_ramb36e2.sv` — RTL-код модуля FIFO.
* `tb/tb_sync_fifo.sv` — Самопроверяемый тестбенч.
* `run_sim.tcl` — Tcl-скрипт для автоматического развертывания проекта и запуска симуляции в Vivado.

## Как запустить симуляцию
Для автоматической проверки модуля не требуется вручную создавать проект. 
В Tcl Console среды Vivado перейдите в директорию задания и выполните скрипт:
```tcl
cd <путь_к_папке>/Task_1_Sync_FIFO
source run_sim.tcl
