# Контроллер светофора (FSM)

## Описание
РЕализация конечного автомата управления светофором на языке SystemVerilog. После инициализации или аппаратного сброса модуль находится в состоянии ожидания, в котором активирован мигающий желтый сигнал с частотой, задаваемой через параметры модуля. Управляющий сигнал инициирует последовательность переключения фаз от красного к желтому, затем зеленому, снова желтому и возврату к красному, после чего автомат возвращается в исходное состояние.

В модуле реализована асинхронная обработка управляющего сигнала во время активной фазы работы светофора. Если управляющий сигнал поступает в первой половине цикла (при переходе от красного к зеленому), логика управления его полностью игнорирует, не прерывая текущую фазу. Если управляющий сигнал фиксируется в фазе завершения цикла (при переходе от желтого к красному), конечный автомат запускает повторный рабочий цикл без предварительного возврата в режим ожидания.

## Особенности реализации
Проект выполнен в стиле поведенческого описания. Для хранения текущего состояния автомата и кодирования выходных сигналов управления лампами применяются enumeration. В качестве внутреннего таймера используется базовая целочисленная арифметика, позволяющая задавать длительность каждой фазы светофора в тактовых импульсах.

## Структура директории
Директория `src` содержит поведенческий RTL-код контроллера светофора `traffic_light.sv`. В директории `tb` расположен тестбенч `tb_traffic_light.sv`, реализующий последовательную проверку всех сценариев работы логики, включая обработку нажатий кнопки в разных состояниях. В корневой папке задания размещен Tcl-скрипт `run_sim.tcl`.

## Запуск симуляции
Для проверки работоспособности модуля используется автоматизированный скрипт для среды разработки Vivado. Для запуска необходимо открыть консоль Tcl, перейти в директорию текущего задания и выполнить команду `source run_sim.tcl`. Среда автоматически сформирует необходимые файлы проекта, выстроит иерархию модулей и запустит процесс симуляции, по завершении которого результаты проверочных тестов будут выведены в консоль.
