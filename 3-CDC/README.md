# Пересечение тактовых доменов (CDC)

## Описание
В данном задании реализованы модули для передачи сигналов между асинхронными тактовыми доменами. Проект основывается на методах, описанных в статье Clifford E. Cummings (SNUG 2008). Комплекс состоит из двух модулей. Первый модуль представляет собой синхронизатор однотактового импульса. Второй модуль предназначен для передачи параметризируемой многобитовой шины данных для редко меняющихся сигналов и работает на логике импульсного синхронизатора.

## Особенности реализации
Синхронизация описана на уровне регистровых передач с использованием каскадов D-триггеров, при этом намеренно исключено использование встроенных библиотечных макросов Vivado (XPM_CDC). Данные защелкиваются в целевом домене строго по приходу синхронизированного сигнала готовности, что исключает возможность захвата нестабильных переходных состояний на многобитовой шине. Тестбенч моделирует условия работы, генерируя два асинхронных тактовых сигнала с частотами 100 МГц для передающего домена и 40 МГц для принимающего домена.

## Структура директории
Директория `src` содержит RTL-коды импульсного синхронизатора `cdc_pulse_sync.sv` и синхронизатора многобитовой шины `cdc_multibit_sync.sv`. В директории `tb` расположен тестбенч `tb_cdc.sv`. Исполняемый скрипт `run_sim.tcl` располагается в корневой папке задания.

## Запуск симуляции
Для автоматической сборки проекта необходимо открыть Tcl Console в среде Vivado, перейти в директорию задания с помощью команды `cd` и выполнить запуск командой `source run_sim.tcl`. Среда автоматически сформирует проект, подключит модули согласно иерархии и проведет проверку целостности данных при пересечении доменов.
