# Пересечение тактовых доменов (CDC)

## Описание
В задании реализованы модули для передачи сигналов между асинхронными тактовыми доменами. Проект основывается на методах, описанных в статье Clifford E. Cummings (SNUG 2008). Комплекс состоит из двух модулей. Первый модуль представляет собой синхронизатор однотактового импульса. Второй модуль предназначен для передачи параметризируемой многобитовой шины данных для редко меняющихся сигналов и работает на логике импульсного синхронизатора.

## Особенности реализации
Синхронизация описана на уровне регистровых передач с использованием каскадов D-триггеров, при этом намеренно исключено использование встроенных библиотечных макросов Vivado (XPM_CDC). Данные защелкиваются в целевом домене строго по приходу синхронизированного сигнала готовности, что исключает возможность захвата нестабильных переходных состояний на многобитовой шине. Тестбенч моделирует условия работы, генерируя два асинхронных тактовых сигнала с частотами 100 МГц для передающего домена и 40 МГц для принимающего домена.

## Структура директории
* `src/cdc_pulse_sync.sv` — RTL-код импульсного синхронизатора.
  `src/cdc_multibit_sync.sv` — RTL-код синхронизатора многобитовой шины.
* `tb/tb_cdc.sv` — Тестбенч.
* `run_sim.tcl` — Tcl-скрипт для автоматического развертывания проекта и запуска симуляции в Vivado.
